# Age, sex, and menopausal status shape plasma amino acid and acylcarnitine levels in healthy adults

Analysis code for the manuscript *Age, Sex, and Menopausal Status Shape Plasma Amino Acid and Acylcarnitine Levels in Healthy Adults: Implications for Reference Intervals* (Goss N, Borreggine R, Teav T, Marques Vidal P, Gallart-Ayala H, Kutalik Z, Ivanisevic J).

Plasma amino acids (AAs) and acylcarnitines (ACs) were quantified in 2576 apparently healthy adults (40-76 years) of the CoLaus|PsyCoLaus study. The code estimates the effects of age, sex, and menopausal status on all metabolites and derives reference intervals (RIs) with a non-parametric, a Box-Cox, and a linear model (LM) approach.

## Structure

Each analysis step has its own folder with the script, its inputs (`01_input`) and its outputs (`02_output`). Later steps read the outputs of earlier steps, so the scripts must be run in order.

| Folder | Content | Manuscript |
|---|---|---|
| `01_technical_qc` | precision (pooled QC) and accuracy (NIST SRM 1950); exclusion of metabolites with CV > 20% | Figures S2-S4, Table S3 |
| `02_preprocessing` | removal of excluded metabolites, averaging of duplicate injections, IQR outlier removal, merging with metadata | – |
| `03_concentration_ranges` | mean concentrations in males, premenopausal and postmenopausal females | Figures 1-2 |
| `04_covariate_effects` | effects of age, sex, menopausal status and their interactions (linear models on log concentrations); cross-validated calibration of the LM-based RIs | Figures 3-4, Figure S5, Tables S4-S5 |
| `05_reference_intervals` | RIs with the non-parametric, Box-Cox, and LM approach | Tables S1, S6-S8 |
| `06_method_robustness` | Jaccard indices of RIs from 100 subsets vs. the full dataset; Cliff's delta between methods | Figure 5 |
| `07_shiny_app` | online calculator of LM-based RIs for any age, sex, and menopausal status | [nicogo.shinyapps.io/ricalculation_app](https://nicogo.shinyapps.io/ricalculation_app/) |

`ri_methods.R` contains the three RI methods, shared by `05_reference_intervals` and `06_method_robustness`. Figure S1 is a schematic and not generated by code.

## Data

The CoLaus|PsyCoLaus data are not publicly available because of participant privacy. They can be requested from the CoLaus|PsyCoLaus study ([www.colaus-psycolaus.ch](https://www.colaus-psycolaus.ch)). To run the analysis, place the following files in `02_preprocessing/01_input`:

- `Resultat CoLaus AA-AC.xlsx`: AA and AC concentrations (sheets `AA` and `AC`)
- `colaus_metadata_harmonized.csv`: participant ID (`pt`), follow-up (`fu`), `sex`, `age`, and menopausal status (`mp`)

The quality control measurements (`01_technical_qc/01_input`) and metabolite annotations (`02_preprocessing/01_input/Metabolite Abbreviations.xlsx`) are included.

## Running the analysis

Open a script in RStudio and source it (the working directory is set to the script's folder automatically), or run all steps from this folder with

```
Rscript run_all.R
```

`06_method_robustness` takes about half an hour; all other steps take less than a few minutes.

The analysis was run with R 4.5.1 and the packages tidyverse 2.0.0 (dplyr 1.1.4, ggplot2 4.0.3), openxlsx 4.2.8, patchwork 1.3.2, RColorBrewer 1.1.3, MASS 7.3.65, car 3.1.5, VGAM 1.1.14, effsize 0.8.1, and, for the app, shiny 1.12.1.

## Shiny app

`05_reference_intervals` writes the LM coefficients and residual limits to `07_shiny_app/lm_constants.csv`, which the app reads. To run the app locally, run `shiny::runApp("07_shiny_app")`. To deploy it to shinyapps.io, register the account once with `rsconnect::setAccountInfo()` (token and secret from the shinyapps.io dashboard; never store them in a script) and run `rsconnect::deployApp("07_shiny_app")`.
